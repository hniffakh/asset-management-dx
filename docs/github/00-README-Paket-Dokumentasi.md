# Denso Internship GitHub Governance Documentation

Paket ini mendokumentasikan baseline konfigurasi GitHub, pembagian tanggung jawab, alur kerja contributor, standar penamaan, dan pengujian akses untuk program internship.

## Urutan dokumen

1. `01-Ringkasan-Konfigurasi-GitHub-Organization` - baseline dan status konfigurasi.
2. `02-SOP-Organization-Owner-DX-Core` - onboarding, repository, akses, governance, dan offboarding.
3. `03-SOP-Karyawan-Denso-Mentor-dan-Project-Owner` - mentor, reviewer, dan project stewardship.
4. `04-SOP-Internship-GitHub-Workflow` - panduan kerja intern.
5. `05-Standar-Penamaan-dan-Git-Workflow` - source of truth penamaan.
6. `08-Quick-Reference-Intern-Git-Workflow` - panduan ringkas harian.
